A booking system for public facilities, built for a local government client. Citizens browse the available spaces — courts, halls, community rooms — and request a booking online. Admins review each request, manage the schedule, catch double bookings, and generate occupancy reports.

Livewire drives the interactive parts, so the project needs no separate frontend build.
